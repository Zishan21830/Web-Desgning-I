# Web Designing I

A collection of HTML exercises and mini-projects created while learning the fundamentals of web design. The repository covers the core building blocks of web pages: document structure, text, links, images, lists, tables, and forms.

## Repository Structure

```
Web-Desgning-I/
├── HTML/          # HTML pages and practice exercises
└── README.md      # Project documentation
```

## Topics Covered

- Basic HTML document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Headings, paragraphs, and text formatting
- Hyperlinks and navigation
- Images and multimedia
- Ordered, unordered, and description lists
- Tables
- Forms and input elements
- Semantic HTML elements (`<header>`, `<nav>`, `<section>`, `<footer>`)

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, or Safari)
- A text editor or IDE such as [VS Code](https://code.visualstudio.com/)

No build tools or dependencies are required.

### Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Zishan21830/Web-Desgning-I.git
   ```

2. Navigate into the project folder:

   ```bash
   cd Web-Desgning-I/HTML
   ```

3. Open any `.html` file in your browser by double-clicking it, or serve the folder locally with the VS Code **Live Server** extension.

## Learning Outcomes

- Write clean, well-structured HTML5 markup
- Build multi-element pages with proper nesting and semantics
- Create navigable pages using links and lists
- Collect user input with forms
